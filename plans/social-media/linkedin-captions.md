## 2. Qual é a versão certa da folha de Excel?

Link: https://formiga.galaticos.pt/notas/qual-e-a-versao-certa-da-folha-de-excel/

"Orcamentos_final.xlsx", "Orcamentos_final2.xlsx", "Orcamentos_final_ESTE.xlsx".

Quando há várias cópias da mesma folha, cada pessoa trabalha com a sua. Cinco passos para pôr ordem:

1. Um único sítio para a folha
2. Dizer quem altera e quem só consulta
3. Usar o histórico de versões em vez de "final2"
4. Separar os dados dos relatórios
5. Perceber quando a folha já faz o trabalho de uma aplicação

Os passos e as explicações:
https://formiga.galaticos.pt/notas/qual-e-a-versao-certa-da-folha-de-excel/

## 3. Orçamentos: quanto tempo demora cada passo?

Link: https://formiga.galaticos.pt/notas/orcamentos-quanto-tempo-demora-cada-passo/

Depois escolha os dois passos mais demorados e pergunte: isto precisa de uma pessoa, ou é só repetir informação que já existe?

## 4. Pedir documentos aos clientes sem andar atrás deles

Link: https://formiga.galaticos.pt/notas/pedir-documentos-aos-clientes/

O pedido vai por email, a resposta vem por WhatsApp, o ficheiro chega com um nome qualquer e alguém tem de o arrumar.

Quatro mudanças que se fazem já:
→ uma lista fixa por tipo de cliente
→ um único sítio para receber
→ nomes de ficheiro previsíveis
→ um lembrete com data

Detalhes e exemplos:

## 5. A mesma informação escrita três vezes

Link: https://formiga.galaticos.pt/notas/a-mesma-informacao-escrita-tres-vezes/

O NIF de um cliente aparece na folha de clientes, no orçamento e na fatura. Cada cópia é mais um sítio para atualizar e mais uma oportunidade para errar.

Um mapa de meia hora:
1. Onde é escrita?
2. Quem a escreve, e quantas vezes por semana?
3. O que acontece quando muda?

Depois, escolha um sítio como fonte. Os outros passam a ler dela.

## 6. O que perguntar antes de pedir uma ferramenta feita à medida

Link: https://formiga.galaticos.pt/notas/o-que-perguntar-antes-de-pedir-uma-ferramenta-feita-a-medida/

Seis perguntas para fazer a quem propõe uma ferramenta feita à medida (a nós incluídos):

1. Qual é o preço, e é fechado?
2. Quando fica pronto?
3. A ferramenta fica sua?
4. Há mensalidades obrigatórias?
5. Quem trata dos problemas depois da entrega?
6. Dá para ver trabalho real?
